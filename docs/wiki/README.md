## Pubblicare come GitHub Wiki

Questi file possono essere copiati nella Wiki del repository GitHub:

1. Vai su **Settings** → abilita **Wiki** (se non attiva)
2. Tab **Wiki** → **Create the first page**
3. Incolla il contenuto di `Home.md` come pagina principale
4. Crea le altre pagine con gli stessi nomi dei file `.md`

In alternativa, la documentazione resta sempre disponibile nella cartella `docs/wiki/` del repository.
